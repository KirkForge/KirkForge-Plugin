# Repository Rules

## Two Repos, Two Roles

| Repo | Path | Role |
|------|------|------|
| **Publish repo** | `/path/to/publish-repo` | Clean source, docs, tracked scripts. No runtime state. |
| **Sandbox** | `/path/to/runtime-sandbox` | Active benchmark/runtime copy. Has `node_modules`, `.env`, Docker access, local state. |

## Source of Truth

- The **publish repo** is the source of truth for all code, docs, and tracked scripts.
- The **sandbox** is a working copy for running benchmarks. It may diverge from the publish repo with local logs, raw JSON reports, and runtime state.
- **Never** run `npm ci`, `npm install`, or benchmark commands from the publish repo. Use the sandbox.

## What Belongs Where

### Publish repo only
- Source code (`packages/`, `apps/`)
- Documentation (`docs/`, `bench/REAL_TBENCH_GUIDE.md`, `bench/README.md`, `REPORULES.md`)
- Tracked scripts (`bench/real-tbench-benchmark.mjs`, `bench/run-model-matrix.sh`, `scripts/`)
- Sanitized result summaries (`bench/results/*.md`)

### Sandbox only
- `node_modules/`
- `.env` (with real API keys)
- Raw benchmark JSON (`/tmp/bench-sandbox/report-real-*.json`)
- Benchmark logs (`bench/*.log`)
- Docker runtime state
- Temp run directories under `/tmp`

### Never in publish repo
- `.env` files (only `.env.example` is tracked)
- `node_modules/`
- `dist/` build output (gitignored, regenerated by `npm run build`)
- Raw `report-real-*.json` files
- `bench/*.log` files
- Local machine-specific paths in any file
- SSH keys, PEM files, or secrets

## Syncing Changes

Use `scripts/sync-to-sandbox.sh` to copy tracked files from publish repo to sandbox:

```bash
# Preview what will be copied
./scripts/sync-to-sandbox.sh --dry-run

# Actually sync
./scripts/sync-to-sandbox.sh
```

This copies source, docs, and bench scripts but never touches sandbox `.env`, `node_modules`, or benchmark reports.

Use `scripts/check-clean-publish-repo.sh` to verify the publish repo has no runtime artifacts:

```bash
./scripts/check-clean-publish-repo.sh
```

## Benchmark Results

- Raw JSON reports go to `/tmp/bench-sandbox/` and the sandbox `bench/` directory.
- Sanitized markdown summaries may be copied back to the publish repo as `bench/results/*.md`.
- Never commit raw `report-real-*.json` or `*.log` files to the publish repo.
- The `.gitignore` already excludes these patterns. The check script verifies compliance.
